# Jaga Rimba — Satu Desa, Banyak Pilihan
Game desa pixel art orisinal dari Dapur Kreatif Scode. Empat peran, sepuluh hari, kegiatan berkebun dan sosial, keputusan dengan dampak tertunda, enam epilog, simpan otomatis, musik opsional, serta QRIS dukungan di akhir.

## Main lokal
Ekstrak ZIP, buka index.html di browser modern. Tidak memerlukan instalasi, database, API key, atau koneksi internet untuk bermain. Tautan rujukan membutuhkan internet. Simpanan berada di browser dan perangkat yang sama; perilaku penyimpanan file lokal dapat berbeda antarbrowser.

## GitHub Pages
1. Buat repository, misalnya jaga-rimba.
2. Upload isi folder ini: index.html, style.css, game.js, assets, dan .nojekyll langsung di root repository. Jangan hanya upload ZIP.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Setelah deployment selesai, buka URL Pages yang diberikan GitHub.

## Kontrol
WASD / panah untuk berjalan; E untuk berinteraksi. Di ponsel gunakan tombol arah dan interaksi. Tombol lokasi menyediakan perjalanan cepat. Rapat Balai desa wajib setiap hari; kegiatan tambahan memakai energi. Tanaman siap dipanen dua hari setelah ditanam. Akhiri hari ke-10 untuk melihat epilog.

## Catatan
Cerita, tokoh, desa, dan angka konsekuensi fiktif. Bukan data real-time, prediksi ilmiah, atau panduan operasi pemadaman. Konteks edukasi dirujuk di menu Rujukan. Semua peran punya pilihan membantu maupun merugikan. Tidak ada kelompok yang otomatis dianggap bersalah.
QRIS merupakan dukungan sukarela kepada pengembang, bukan dana bantuan karhutla. Grafik dibuat melalui Canvas; tidak menggunakan aset Harvest Moon.

## Validasi
Sintaks JavaScript dan pengujian logika melalui lingkungan DOM tiruan, mencakup semua peran, sepuluh hari, pilihan, dampak tertunda, penyimpanan, panen, serta tampilan epilog. Pengujian browser visual belum dilakukan pada lingkungan pembuatan.
